# Installation / Instalación

EN: Create `~/.local/share/kdenlive/effects/` if needed. Extract the XML files into that directory, restart Kdenlive, and search for the effect by name. Use the matching project resolution. Keyframes span 0–149 (150 frames, five seconds at 30 fps). Other frame rates or resolutions may require adjustment.

ES: Crea `~/.local/share/kdenlive/effects/` si no existe. Extrae los XML allí, reinicia Kdenlive y busca el efecto por nombre. Usa la resolución correspondiente. Los fotogramas clave abarcan 0–149 (150 fotogramas, cinco segundos a 30 fps). Otras resoluciones o tasas pueden requerir ajustes.
